# A/C Compressor (Remove and Replace) — Model 3 2024+

Installation procedure. Torque values as published in the Tesla Model 3 2024+ Service Manual.

## Installation

1. Position the A/C compressor assembly under the strut tower brace.

2. Install the HV harness cover to the A/C compressor.

3. Position the A/C compressor bracket on the A/C compressor, then install the three bolts that attach the bracket to the compressor. Torque to 9 Nm (6.6 lbs-ft). Recommended tools: 10 mm deep socket, cordless ratchet or impact driver, ratchet or torque wrench.

4. With an assistant supporting the A/C compressor assembly under the strut tower brace, hand-start the two bolts that attach the A/C compressor assembly to the brace, then torque the bolts to 31 Nm (22.9 lbs-ft). Recommended tools: 15 mm socket, cordless ratchet or impact driver, ratchet or torque wrench.

5. Replace the O-rings on the high pressure and low pressure supermanifold to A/C compressor hose fittings. O-ring for the high pressure line is part 1111737-00-A, WASHER, 3/8, STL ZN, SEAL. O-ring for the low pressure line is part 1111740-00-A, WASHER, 3/4, STL ZN, SEAL. Lubricate the O-rings with ND-11 oil prior to installation.

6. Remove the transport plugs from the new compressor. Recommended tool: 13 mm socket.

7. Position the supermanifold to A/C compressor high pressure fitting on the A/C compressor, then install the nut that attaches the fitting to the A/C compressor. Torque to 22 Nm (16.2 lbs-ft). Recommended tool: 13 mm deep socket.

8. Position the supermanifold to A/C compressor low pressure fitting on the A/C compressor, then install the nut that attaches the fitting to the A/C compressor. Torque to 22 Nm (16.2 lbs-ft). Recommended tool: 13 mm deep socket.

9. Install a new desiccant. See the Desiccant (Remove and Replace) procedure. Reuse the accumulator cap and the snap ring used during flushing.

10. Perform the vacuum leak test and refill the A/C refrigerant. See the A/C Refrigerant (Recovery and Recharge) procedure.

11. Install the two clips that attach the coolant hose to the A/C compressor bracket.

12. Install the clip that attaches the coolant hose to the A/C compressor bracket.

13. Position the ground strap on the A/C compressor, then install the bolt that attaches the ground strap to the A/C compressor. Torque to 7 Nm (5.2 lbs-ft). Recommended tools: Torx T25 socket, cordless ratchet or impact driver, ratchet or torque wrench.

14. Position the A/C compressor HV harness to the A/C compressor.

15. Install the bolt that attaches the A/C compressor HV harness bracket to the A/C compressor. Torque to 9 Nm (6.6 lbs-ft). Recommended tools: 13 mm 12-point deep socket, cordless ratchet or impact driver, ratchet or torque wrench for installation only.

16. Connect the HV harness electrical connector to the A/C compressor.

17. Install the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.

18. Connect the A/C compressor logic electrical connector to the A/C compressor, then engage the locking tab. Push the red locking tab into the connector to engage the locking mechanism. Do not push down or pull up on the red locking tab.

19. Install the LV battery. See the LV Battery (Remove and Replace) procedure.

20. Install the 2nd row lower seat cushion. See the Seat Cushion - 2nd Row (Remove and Replace) procedure.

21. Connect LV power. See the LV Power (Disconnect and Connect) procedure.

22. Connect an LV maintainer. See the LV Maintainer (Connect and Disconnect) procedure.

23. Enable Service Mode.

24. Unlock the vehicle gateway. See the Gateway Unlock procedure.

25. Set the compressor type using the touchscreen. For vehicles running firmware 2026.2.3 or later (NA/EMEA) or 2025.44.32 or later (APAC), touch Thermal, then Actions, then Configure Compressor, then touch Run to start the routine. For vehicles running earlier firmware, touch Thermal, then Actions, then Thermal Configurations, then compressorType, and select and save the correct compressor type. Afterwards, check the gateway configuration for compressorType and confirm it shows as intended.

26. Reinstall the software. See the Software Reinstall - Touchscreen procedure.

27. On the touchscreen, perform the following routines, confirming each one passes before closing it:
    - Touch Controls, then Thermal, then Sensors and Valves, then Reset Compressor P-Metric, and click Run.
    - Touch Thermal, then Refrigerant System, then Run Heat Pump Commissioning, and select Run.
    - Touch Thermal, then Actions, then Test HVAC Performance, and select Run.
    - Touch Thermal, then Actions, then Test Thermal Performance, and select Run.

28. Disable Service Mode.

29. Disconnect the LV maintainer.

30. Install the underhood storage unit. See the Underhood Storage Unit (Remove and Replace) procedure.

31. Raise all windows and close the doors.
